Sou desenvolvedor backend de Minas Gerais. Comecei a programar em 2023 como autodidata e hoje estudo **Sistemas de Informação na PUC Minas**.

## 🚀 Projeto principal — [GopherNet](https://github.com/CiceroGGS/GopherNet)

Rede social inspirada no Twitter, com **API REST em Go** e front-end web também em Go.

- **Autenticação:** login com JWT (expira em 6h) e senhas com bcrypt
- **Funcionalidades:** usuários, seguidores, publicações e curtidas
- **Arquitetura em camadas:** router → middleware → controller → repository → MySQL
- **Middlewares** de log de requisições e validação de token nas rotas protegidas
- **Próximos passos:** Docker Compose, testes automatizados e documentação com Swagger
